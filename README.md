# 鋼脚戦記 南島1965

歩行戦車部隊で島を北へ攻め上がる、ブラウザで遊べる戦略アクションの試作。

## 遊び方
`index.html` をブラウザで開くだけ(ビルド不要・1ファイル完結)。

- 作戦地図で拠点を選んで出撃、敵と1機ずつ一騎打ち
- 照準は操縦席の潜望鏡から。ブレる照準を敵に重ねて撃つ(弱点：覗き窓・機関部・ハッチ)
- 損傷は持ち越し。格納庫で修理・改造・分隊編成
- 乗員3人(操縦手・砲手・装填手)と分隊がそれぞれ育つ。全滅してゲームオーバーになっても乗員Lvと分隊★は引き継ぎ
- 機体6種を買い替え、左右の腕に7種の武器を別々に装備(戦闘中に切替)
- 戦闘離脱(背を向けて全力で逃げる)、制圧済み拠点は何度でも再戦
- 撃った弾をカメラが追いかける弾丸カメラ、機体性能に応じて自動でかわす回避モード

## 操作
- マウス：動かして狙う、クリックで発射
- スマホ：画面をなぞって照準、「撃て!」で発射
- キー：A/D 移動、Space 照準/発射、照準中は WASD・矢印、X 解除、Q/E 左右の腕、V 回避モード、F 離脱、1〜2 分隊、P 停止

架空の戦後史を舞台にしたオリジナル作品。進行はブラウザの localStorage に保存。
