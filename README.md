# 鋼脚戦記 南島1965

歩行戦車部隊で島を北へ攻め上がる、ブラウザで遊べる戦略アクションの試作。

## 遊び方
`index.html` をブラウザで開くだけ(ビルド不要・1ファイル完結)。

- 沖縄本島の作戦地図を喜屋武岬から辺戸岬まで攻め上がる。拠点で敵と1機ずつ一騎打ち
- 那覇・嘉手納・名護にボス、最後の辺戸岬に大ボス「大要塞テンカ」(半分削ると暴走)
- 照準は操縦席の潜望鏡から。ブレる照準を敵に重ねて撃つ(弱点：覗き窓・機関部・ハッチ)
- 損傷は持ち越し。格納庫で修理・改造・分隊編成
- 乗員3人(操縦手・砲手・装填手)と分隊がそれぞれ育つ。全滅してゲームオーバーになっても乗員Lvと分隊★は引き継ぎ
- 機体6種を買い替え、左右の腕に7種の武器を別々に装備(戦闘中に切替)
- 戦闘離脱(背を向けて全力で逃げる)、制圧済み拠点は何度でも再戦
- 作戦地図：制圧済み拠点につながる目標を自由に選ぶ。合流する両ルートを先に取ると挟撃で守備隊装甲が12%減る
- 補給：初制圧で1、港と飛行場では3獲得（上限12）。補給2で初戦の自機を整備、補給3で守備隊全機に支援砲撃。通常出撃には補給不要
- 砲弾の真後ろから敵へ飛んでいく弾丸カメラ。武器ごとに発射・弾道・着弾・音の演出が違う、機体性能に応じて自動でかわす回避モード

## 操作
- 作戦盤：味方全機を六角マスに展開。左側2列で配置して「配置完了」。各機はターンごとに移動と交戦を1回ずつ行える
- 林・廃墟は移動力を2消費し、水域は通行不可。射程内の敵を選ぶとリアルタイム狙撃に移行し、戦闘後は損傷・撃破を反映して作戦盤へ戻る。「ターン終了」で敵部隊が行動する
- マウス：動かして狙う、クリックで発射
- 左右の武器ボタン：1回目で武器を選んで照準、同じボタンの2回目で発射。照準中に反対のボタンを押すと武器だけ切り替わる
- スマホ：画面をなぞって照準し、同じ武器ボタンで発射
- キー：A/D 移動、Space 照準/発射、照準中は WASD・矢印、X 解除、Q/E 左右の腕、V 回避モード、F 離脱、1〜2 分隊、P 停止

架空の戦後史を舞台にしたオリジナル作品。進行はブラウザの localStorage に保存。
